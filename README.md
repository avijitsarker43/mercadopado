# Joomla OS Membership Mercadopago Payment plugin

A Joomla 4 OS Membership Payment plugin that integrates with the com_osmembership component and Mercadopago payment gateway.

## Installation

1. Download or clone the plugin repository
2. Copy the `mercadopado` folder to `/components/com_osmembership/plugins` in your Joomla installation
3. Go to Joomla Administration > Components > OS Membership > Plugins
4. Find and enable the "OS Mercadopago" plugin
5. Configure the plugin settings as needed


### Basic Settings
You have to collect mercadopago payment systems API Credentials

## Requirements

- Joomla 4.0 or higher
- PHP 7.4 or higher
- com_osmembership component installed and enabled
